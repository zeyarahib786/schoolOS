# Archived project material

`removed-pre-consolidation-20260910/` is the recoverable snapshot of files and folders removed
during the client/server consolidation. It includes the former feature-based client, historical
reports and setup documents, accessibility scripts, and the prior manifest.

This archive is intentionally not part of the production build. The reusable React feature source
has also been merged into `client/src/features`, `client/src/components`, and `client/src/lib`.
